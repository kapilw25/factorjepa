# VM41 — stub sub-column shipped with an EMPTY header cell

**Mistake.** A two-stub table (Suite | I/Δ | methods...) left the header cell over the
second stub blank (`Suite & & DPO & ...`), so rows read "LITMUS (AQI) I 11.8" and the
bare "I" was explained only in the caption. The same letter was italic $I$ = instruction
everywhere else in the paper, so one glyph carried two meanings.

**Root cause.** `&` left empty in the header row; row label chosen as a single letter
that collides with a symbol already used in the prose.

**Fix.** Every column, including stub/metric columns, carries a header word ("Score"),
and the row label is a word ("Instruct"), never a letter that is a symbol elsewhere.

**Prevention (audit).** Scan the header row for a column whose header cell has no word;
grep the paper for every single-letter row label and check it is not also a math symbol.
