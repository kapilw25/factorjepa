## VM40 — Illustration rasters pasted at a fraction of their authored width carry baked-in text far below the 9-pt floor while the compositor's own labels mask it (2026-09-21)

Context: `denseworld_teaser.png` (AAAI-27 Student Abstract, Figure 1) pastes ten scene thumbnails and the three 1448x1086 factor panels (agents / layout / interactions) into one 7-in-wide composite.

- **Symptom.** The compositor's own `(a) Agents / (b) Layout / (c) Interactions` labels are 10 pt, so the figure "looked" compliant, but the pasted panels (scaled x0.472) carry tags and a legend that print at 1.7-6.4 pt: (b) black-on-white boxes ~6.4 pt, (b) white-on-colour ~3.9 pt, (c) legend ~3.4 pt and regular weight, (a) tags ~1.7-2.2 pt. All under the AAAI 9-pt rule for text inside illustrations.
- **Root cause.** The legibility check (C5) was applied to the text the script draws, not to text INSIDE the pasted rasters; the downscale is invisible in the compositing script.
- **Fix.** Before compositing, measure the smallest baked cap height per source panel and convert to print points (`cap_px / source_px_per_placed_inch * 72 / 0.72`); if < 9 pt, regenerate that panel's labels at >= 79-px em (one tag per class, not nine `Pedestrian` tags) or move an in-panel legend into the caption. For the abstract, the (c) legend's meaning (circles = tracked agents, colour = flow direction) was moved into the LaTeX caption; the panels themselves still need regeneration.
- **Prevention.** C5 covers every pixel of text in the placed artifact, including pasted images; record each source panel's effective minimum point size in the compositor's docstring.
