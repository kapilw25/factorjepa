# VM43 — table note set as a free paragraph, hanging outside a centred table

**Mistake.** The legend note under a `\centering` single-column table was typeset as a
free `\raggedright` paragraph, so it started at the column margin (x = 54 pt) while the
table's rules started 19 pt further right; the note visibly hung outside the table.

**Root cause.** Note placed after `\end{tabular}` as body text; the tabular is narrower
than the column and centred, the paragraph is not.

**Fix.** Put the note inside the tabular as the last row:
`\multicolumn{N}{@{}>{\raggedright\arraybackslash}p{<table width>}@{}}{...}` after
`\bottomrule` (or use threeparttable), so its left edge equals the rule's left edge.

**Prevention (audit).** Measure note x0 and rule x0 on the render; they must be equal.
