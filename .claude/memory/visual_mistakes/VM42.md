# VM42 — multi-line transcript rows with no separation between entities

**Mistake.** A full-width transcript table (one trainer per row, 2-3 wrapped lines per
cell) used plain booktabs rows: the pitch between trainer rows (10 pt) equalled the pitch
inside a cell, so the four trainers blurred into one text block and the verdict of one
row sat at the same leading as the first line of the next.

**Root cause.** booktabs body with wrapped p-columns and no `\addlinespace` or rule
between entities; verdicts placed LAST so wrapping left lone "[repetitive]" lines.

**Fix.** `\addlinespace[3pt]` between entity rows, `>{\raggedright\arraybackslash}`
p-columns (no hyphen at a column boundary), and the verdict FIRST in each cell so a
dangling last line is quoted text, never a lone verdict. Pay for the added height by
abridging the quotes.

**Prevention (audit).** Measure inter-row vs intra-row pitch on the render; equal pitch
= FAIL. Check that no cell's last line is a single bracketed token.
